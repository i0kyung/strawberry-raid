# 딸기 습격

꼬마 소인이 되어, 인간이 자리를 비운 사이 식탁 위 딸기 디저트를 해치우는 3D 웹 게임입니다.
설치 없이 휴대폰과 PC 브라우저에서 바로 할 수 있어요.

**바로 하기:** https://i0kyung.github.io/strawberry-raid/

## 첫 화면

- 식탁 위 한 자리처럼 생겼어요. 깅엄 냅킨 위에 제목, 양옆에 포크와 숟가락, 가운데에 검색창.
- 디저트 묶음 10판이 카드로 나옵니다. 한 판에 접시 세 개, 디저트 세 가지가 함께 나와요.
- **검색**: 묶음 이름이나 디저트 이름으로 찾습니다. 초성만 쳐도 돼요 (예: `ㅁㅋㄹ` → 마카롱).
- **정렬**: 검색창 아래 왼쪽 「인기순 ▾」에서 인기순(많이 부순 순) · 이름순
- **즐겨찾기**: 카드 오른쪽 위 딸기를 누르면 빨갛게 익어요. 검색창 아래 오른쪽 딸기 버튼으로 즐겨찾기만 모아 볼 수 있어요. 이 기기에 저장됩니다.
- **모두의 기록**: 「지금까지 N명이 디저트 M조각을 부숴버렸어요」. 아래 *모두의 기록 켜기*를 하기 전에는 이 기기 기록만 보여요.
- 의견과 추가 디저트 신청은 인스타 **@i0k.zip** DM으로 받습니다.

## 하는 법

- 첫 화면에서 묶음을 고르거나 「처음부터」를 누르면 짧은 연출이 나와요. 꼬마 등 뒤에서 거대한 디저트를 올려다보는데 쿵… 쿵…! 쿵!! 인간이 지나가고, 꼬마가 「인간… 복수할테다…!」. 화면을 누르거나 Esc로 건너뛸 수 있고, 「다음 묶음」으로 넘어갈 때는 나오지 않아요.

- 디저트를 누르면 꼬마가 그곳으로 달려가거나 폴짝 뛰어 공격합니다. 화면을 끌면 돌아가고, 휠이나 두 손가락으로 확대합니다.
- **인간을 조심하세요.** 조용하던 식탁에 발소리가 들리기 시작하면(빨간 테두리, 「발소리 주의!」) 서둘러 숨어야 합니다.
  - **숨기** 버튼(또는 Space)을 누르면 가장 가까운 숨는 곳으로 달려가요. 식탁 가장자리의 쪽지 텐트, 머그컵, 설탕 그릇을 직접 눌러 골라도 됩니다.
  - 인간이 오면 거대한 눈이 내려다보고, 노란 시선 원이 식탁을 훑습니다. 숨지 않은 채 시선에 걸리면 「들켰다!」 딸기 목숨 하나가 줄어요.
  - 인간이 돌아가면 다시 나와서 습격을 이어 가세요. 들키지 않고 넘기면 은신 보너스 +150.
  - 인간은 갈수록 더 자주 오고, 시선 원도 커집니다.
- 세 접시를 합쳐 90% 해치우면 「완전 범죄!」(남은 목숨과 은신 횟수가 보너스), 딸기 목숨 3개를 다 잃으면 「들켰다!」로 끝납니다.
- 도구 다섯 가지 (숫자 키 1~5)
  - 바늘검: 콕콕 두 번 찔러 주변 조각을 튕겨 냅니다.
  - 포크: 찍어서 식탁 밖으로 휙 던집니다. 바닥까지 떨어뜨리면 「장외」 보너스.
  - 숟가락: 크게 한 숟갈 떠서 냠냠. 떠먹은 조각은 사라지고 점수가 큽니다.
  - 뿅망치: 내리쳐서 납작하게 만들고 크림을 사방으로 튀깁니다.
  - 블루베리 폭탄: 도화선 달린 블루베리를 던지고 도망가면, 카메라가 한 발 물러나 멀리서 「펑!!!」 보라색 충격파와 즙, 부스러기가 사방으로 튀어요. 너무 가까우면 꼬마도 날아갑니다.
- 도구를 바꿔 가며 쓰면 콤보 배율이 올라가고(최대 ×3), 공중에 뜬 조각을 맞히면 공중 콤보 보너스.
- 랭크: 소곤소곤 → 야금야금 → 와구와구 → 대습격 → 디저트 멸망
- 부서진 디저트는 각진 부스러기와 뽀얀 가루가 되어 식탁에 한동안 남아요.
- 묶음마다 최고 점수와 완전 범죄 도장이 남습니다. 게임 중 **홈** 버튼으로 첫 화면에 돌아가요.
- 결과 화면의 **결과 카드 저장**은 지금 화면과 점수를 한 장의 이미지로 만들어 공유하거나 저장합니다.
- 연출 켬/끔 버튼으로 블루베리 폭발 연출(카메라 이동)을 끌 수 있어요. 연출 중에 화면을 누르거나 Esc를 누르면 건너뜁니다.
- 주소 끝에 `?fast`를 붙이면 인간이 금방 찾아와서 숨기를 바로 시험해 볼 수 있어요.

## 만든 방법

- 3D는 [three.js](https://threejs.org/) r160을 CDN으로 불러옵니다. 빌드 도구 없이 HTML 한 파일입니다.
- 디저트는 미리 조각으로 나눠 두고, 조각마다 시트·크림·잼·커스터드 층 색을 칠해 둬서 잘린 면에 단면이 보입니다. 받치던 조각이 빠지면 위의 조각이 차례로 무너집니다.
- 재질에는 셰이더로 잔잔한 얼룩, 스펀지 기공, 딸기 씨를 그려 넣었고, 방 조명 반사(RoomEnvironment)로 시럽·유리·설탕 코팅이 반짝입니다.
- 물리는 라이브러리 없이 직접 짰습니다. 중력, 바닥 튕김, 마찰, 조각끼리 부딪힘, 머그컵 충돌, 멈춘 조각 재우기만 있어요.
- 꼬마 캐릭터는 AI로 만든 3D 모델(270만 면, 색 없음)을 5만 4천 면으로 줄이고, 4면 턴어라운드 그림을 모델에 투사해 색을 입힌 뒤 meshopt로 압축했습니다(65MB → 790KB). 색은 그림에서 가장 정면으로 보이는 방향 위주로 칠하고 채도와 대비를 살짝 올려 또렷하게 했어요.
- 효과음은 [Kenney](https://kenney.nl)의 무료 효과음 팩(Impact Sounds, Interface Sounds, RPG Audio, Sci-fi Sounds, CC0 = 저작권 없음, 상업적 이용 가능, 출처 표시 의무 없음)을 잘라 쓰고, 블루베리 폭탄 「펑」과 인간 발소리 「쿵」은 그 소리 여러 개를 겹쳐 새로 만들었어요. 꼬마 목소리, 도화선, 승리 멜로디는 Web Audio로 합성합니다.

### 파일

- `src/game.html` — 게임 원본 (여기를 고칩니다)
- `tools/build.py` — `python3 tools/build.py` 하면 `index.html`을 다시 만듭니다
- `index.html` — GitHub Pages에 올라가는 완성 페이지
- `assets/character.glb` — 꼬마 캐릭터 (웹용으로 줄인 모델)
- `assets/hero.webp` — 첫 화면 꼬마 그림 (턴어라운드 앞모습을 잘라 씀)
- `supabase/schema.sql` — 모두의 기록용 표와 함수
- `assets/sfx/` — 효과음 (Kenney CC0를 다듬은 mp3)
- `assets/tools/` — 도구 그림, 블루베리 폭탄·딸기 목숨 아이콘
- `assets/fonts/` — 글꼴
- `원본/` — 원본 그림과 원본 3D 모델 (65MB 모델은 `.gitignore`로 저장소에서 뺐습니다)

`src/game.html` 위쪽 `CONFIG`에서 후원 계좌(`sponsorBank`, `sponsorAccount`), 후원 링크(`sponsorUrl`, `bmcUrl`), 결과 카드 주소(`siteUrl`), 모두의 기록(`supabaseUrl`, `supabaseKey`), 딸기 목숨 수(`lives`), 인간이 오는 간격(`quiet`·`warn`·`look`)을 바꾸고 다시 빌드하세요.

### 모두의 기록 켜기 (선택, 무료)

SMASH처럼 「몇 명이 몇 조각 부쉈는지」를 모든 사람이 함께 보려면 기록을 모아 둘 서버가 필요해요. [Supabase](https://supabase.com) 무료 요금제로 충분합니다.

1. Supabase에서 새 프로젝트를 만듭니다.
2. **SQL Editor**에 `supabase/schema.sql` 내용을 통째로 붙여 넣고 **Run**.
3. **Project Settings → API**에서 Project URL과 공개 키(anon 또는 publishable)를 복사해 `CONFIG`의 `supabaseUrl`, `supabaseKey`에 넣고 빌드합니다.

공개 키는 페이지에 그대로 보여도 괜찮아요. 표는 직접 읽거나 고칠 수 없고, 정해진 두 함수(기록 더하기, 기록 보기)로만 쓸 수 있게 막아 두었습니다. 사람 수는 기기마다 만든 익명 번호로 셉니다.
